# Assets

This folder holds static assets for the auramind.cloud site: images, logos, and other media.

- **Path in project:** `site/auramind.cloud/assets/`
- **URL path:** `/assets/` (e.g. `/assets/logo-header.jpg`)

Put images and other assets here and reference them in HTML/CSS as `/assets/filename.ext`.

**In use:** `logo-header.jpg`, `hero-kl-towers.png`, `pattern-bg.png`, `dollar_sign_PNG.png`, `card-idc-operations.jpg`, `card-expert-operations.jpg`, `card-ai-it-services.jpg`, `card-custom-server.jpg`, `card-ai-infrastructure.jpg`, `card-b2b-solutions.jpg`, `card-ai-operation-maintenance.jpg`, `card-customer-service-24-7.jpg`, `card-contact-support.jpg`. Unused files (e.g. `card-ai-consultancy.jpg`, `hero-services.png`) have been removed.
